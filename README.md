# Screen Translator for Windows

Мгновенный перевод выделенной области экрана на русский язык. Сделайте снимок через `Win + Shift + S` — приложение распознает текст из буфера обмена и покажет перевод в полупрозрачном glass-overlay.

> Проект находится в стадии первой публичной версии. Он уже пригоден для ежедневного использования, но OCR и позиционирование overlay имеют описанные ниже ограничения Windows.

## Возможности

- автоматическое обнаружение снимков в Clipboard;
- локальное распознавание через Windows OCR;
- перевод только нерусского текста;
- Google Translate без обязательного ключа или настраиваемый LibreTranslate;
- сохранение заголовков, абзацев и маркированных списков;
- liquid-glass фон с лёгким размытием;
- большой индикатор во время OCR и перевода;
- быстрый эффект появления текста;
- прокрутка колесом мыши;
- изменение размера за края и углы overlay;
- выделение одного или нескольких текстовых блоков мышью;
- копирование выделенного через `Ctrl+C` и выделение всего через `Ctrl+A`;
- прокрутка длинного перевода колесом мыши;
- более точное сохранение жирных заголовков и строк;
- перетаскивание окна, закрытие через `Esc` или двойной щелчок;
- постоянная работа в системном трее;
- portable single-file EXE без установки .NET.

## Быстрый старт

1. Скачайте `ScreenTranslator.exe` из раздела [Releases](../../releases).
2. Запустите файл. Значок приложения появится в системном трее.
3. Нажмите `Win + Shift + S` и выделите область с текстом.
4. Дождитесь окончания распознавания и перевода.

Правый щелчок по значку в трее открывает команды **Перезагрузить** и **Выход**. Команда «Перезагрузить» перечитывает JSON-настройки без перезапуска процесса.

## Управление overlay

| Действие | Управление |
|---|---|
| Переместить | Перетащить внутреннюю область мышью |
| Изменить размер | Потянуть за любой край или угол |
| Прокрутить | Колесо мыши |
| Выделить текст | Щёлкнуть по строке или протянуть через несколько строк |
| Копировать выделенное | `Ctrl+C` |
| Выделить весь перевод | `Ctrl+A` |
| Закрыть | `Esc` или двойной щелчок |

## Настройки

При первом запуске рядом с EXE создаётся `ScreenTranslator.settings.json`. Пример находится в [`ScreenTranslator.settings.example.json`](ScreenTranslator.settings.example.json).

```json
{
  "OcrLanguages": ["en-US", "ru-RU"],
  "TranslationProvider": "google",
  "LibreTranslateUrl": "https://libretranslate.com/translate",
  "LibreTranslateApiKey": "",
  "OverlayOpacity": 0.93,
  "TypingDelayMs": 12,
  "MaxOverlayWidth": 980,
  "FontFamily": "Segoe UI Variable Text",
  "FontSize": 18
}
```

После редактирования выберите **Перезагрузить** в меню трея.

### Перевод

По умолчанию используется публичный endpoint Google Translate. Ключ не нужен, но требуется интернет и доступность сервиса не гарантируется. Для собственного LibreTranslate укажите:

```json
{
  "TranslationProvider": "libretranslate",
  "LibreTranslateUrl": "https://your-server.example/translate",
  "LibreTranslateApiKey": "your-key"
}
```

Не публикуйте файл настроек с настоящим API-ключом. При ошибке перевода приложение показывает распознанный оригинал.

## Требования

- Windows 10 версии 2004 или новее либо Windows 11;
- 64-битная система;
- языковые компоненты Windows OCR для нужных языков;
- интернет для автоматического перевода.

Если английский текст распознаётся похожими кириллическими символами, установите компонент **English OCR**: **Параметры → Время и язык → Язык и регион → English → Параметры языка**. Аналогично установите Russian OCR для русского текста.

## Ограничения

- Clipboard Windows содержит изображение, но не координаты выделенной области. Поэтому overlay появляется рядом с курсором и получает размер снимка в пределах рабочего экрана.
- Точность зависит от масштаба, контраста, шрифта и установленных языков Windows OCR.
- Смешанные языки в одной строке сложнее для локального OCR. Приложение сравнивает результаты английского и русского движков и выбирает наиболее чистый вариант.
- Публичный endpoint Google Translate не имеет SLA. Для стабильного использования настройте собственный LibreTranslate.
- На старых выпусках Windows визуальный glass-эффект может отличаться от Windows 11.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) на Windows.

```powershell
dotnet publish .\src\ScreenTranslator\ScreenTranslator.csproj `
  -c Release -r win-x64 --self-contained true `
  -o .\artifacts\ScreenTranslator
```

Готовый single-file EXE появится в `artifacts/ScreenTranslator`.

## Архитектура

- `TrayContext` следит за Clipboard и управляет жизненным циклом приложения.
- `OcrService` запускает доступные Windows OCR-движки и выбирает результат.
- `Translator` пропускает русский текст и вызывает выбранный сервис перевода.
- `OverlayForm` рисует glass-overlay, загрузку, типографику и прокрутку.
- `Settings` хранит пользовательскую конфигурацию рядом с EXE.

## Конфиденциальность

OCR выполняется локально. На сервис перевода отправляется только распознанный нерусский текст — само изображение не загружается. Подробнее см. [SECURITY.md](SECURITY.md).
