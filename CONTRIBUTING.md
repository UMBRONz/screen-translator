# Участие в разработке

Спасибо за интерес к Screen Translator.

## Сообщение об ошибке

Укажите версию Windows, язык OCR, ожидаемый результат и фактическое поведение. Скриншоты приветствуются, но предварительно удалите личные данные.

## Изменения кода

1. Создайте fork и отдельную ветку.
2. Соберите проект командой из README.
3. Проверьте запуск `ScreenTranslator.exe --smoke-test`.
4. Не добавляйте API-ключи, локальные настройки, логи или собранные бинарники.
5. Опишите назначение и проверку изменения в pull request.

Старайтесь сохранять single-file поставку, работу без прав администратора и понятный fallback при недоступности внешних сервисов.
