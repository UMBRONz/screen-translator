# Безопасность и конфиденциальность

## Обработка данных

- Снимок экрана обрабатывается локально через Windows OCR и не загружается приложением.
- Нерусский распознанный текст отправляется выбранному сервису перевода.
- При стандартной настройке это публичный endpoint Google Translate; при `libretranslate` — сервер, указанный пользователем.
- API-ключ LibreTranslate хранится в JSON рядом с EXE. Защитите файл средствами учётной записи Windows и не публикуйте его.

## Сообщение об уязвимости

Не публикуйте сведения об активно эксплуатируемой уязвимости в открытом issue. Используйте приватное сообщение владельцу репозитория через GitHub Security Advisories после включения этой функции.

Поддерживаемая версия: последний опубликованный релиз.
